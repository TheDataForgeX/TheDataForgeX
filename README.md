### Project Overview

An end-to-end Data Analytics and Machine Learning project designed to analyze air pollution patterns and predict the Air Quality Index (AQI).

### Key Features

- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Missing Value Analysis
- Correlation Analysis
- Data Visualization
- Linear Regression
- Random Forest Regression
- AQI Prediction Dashboard

### Model Performance

| Model | MAE | RMSE | R² |
|:---|---:|---:|---:|
| Linear Regression | 31.17 | 59.45 | 0.807 |
| Random Forest | 20.83 | 40.84 | 0.909 |
