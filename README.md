### 📌 PROJECT OVERVIEW

An end-to-end Data Analytics and Machine Learning project focused on analyzing air pollution patterns and predicting the Air Quality Index (AQI).

### ⚡ KEY FEATURES

- Exploratory Data Analysis (EDA)
- Data Cleaning and Preprocessing
- Missing Value Analysis
- Correlation Analysis
- Data Visualization
- Linear Regression
- Random Forest Regression
- AQI Prediction Dashboard

### 📈 MODEL PERFORMANCE

| Model | MAE | RMSE | R² |
|:---|---:|---:|---:|
| Linear Regression | 31.17 | 59.45 | 0.807 |
| Random Forest | 20.83 | 40.84 | 0.909 |
